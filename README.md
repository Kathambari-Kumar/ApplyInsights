**ApplyInsights**

**Tech Stack:** Python, Flask, MySQL, Matplotlib

**Overview:**
ApplyInsights is a data analytics application that processes job-related email data through 
an automated ETL pipeline and generates insights through visual dashboards.

**Features**<br>
Extract, transform and load (ETL) job-related email data<br>
Data normalization and cleaning<br>
Monthly trend analysis<br>
City-wise analytics dashboards<br>
Automated validation checks for ETL workflows<br>
Workflow documentation and troubleshooting support<br>

**Technologies:**
Python,
Flask,
MySQL,
Matplotlib.

**Key Learnings**<br>
1) ETL workflow design<br>
2) Data cleaning and normalization<br>
3) Backend development with Flask<br>
Dashboard creation and data visualization
Automated testing and validation
