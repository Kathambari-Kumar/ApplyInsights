**ApplyInsights**

**Tech Stack:** Python, Flask, MySQL, Matplotlib

**Overview:**
ApplyInsights is a data analytics application that processes job-related email data through 
an automated ETL pipeline and generates insights through visual dashboards.

**Features**
Extract, transform and load (ETL) job-related email data<br>
Data normalization and cleaning
Monthly trend analysis
City-wise analytics dashboards
Automated validation checks for ETL workflows
Workflow documentation and troubleshooting support

**Technologies**
Python
Flask
MySQL
Matplotlib

**Key Learnings**
ETL workflow design
Data cleaning and normalization
Backend development with Flask
Dashboard creation and data visualization
Automated testing and validation
